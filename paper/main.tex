\begin{abstract}
    Orthographic nativization, generating standardized spellings for loanwords, is essential for consistent text processing in multilingual settings, yet computational approaches remain scarce. We present a rule-based cascade algorithm for orthographic nativization, using English loanwords in Filipino as a testbed. The system operates through tokenization, priority-ordered rewrite rules, phonetic disambiguation via grapheme-to-phoneme conversion, and output normalization. All rules derive from prescriptive spelling guidelines and descriptive accounts of Filipino orthography and phonology. Evaluation against a gold-standard corpus using Character Error Rate shows that encoding linguistic rules in a rewrite cascade provides an effective and interpretable low-resource solution.
\end{abstract}

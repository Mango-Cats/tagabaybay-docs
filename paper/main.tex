\begin{abstract}
    Orthographic nativization, the task of generating standardized spellings for loanwords, is essential for consistent text processing in multilingual settings, yet computational approaches remain scarce, particularly for low-resource languages. We present a rule-based cascade algorithm for the orthographic nativization of English loanwords, using Filipino as a computational testbench. The system performs orthographic nativization through sequential stages of tokenization, priority-ordered rule application, phonetic disambiguation via a grapheme-to-phoneme component, and output normalization. All rules are derived from prescriptive spelling guidelines and descriptive accounts of Filipino orthopraphy and phonology. Evaluation against a gold-standard corpus spanning Philippine domains where English is frequently used, using Character Error Rate, shows that explicitly encoding linguistic rules in a rewrite cascade provides an effective and interpretable low-resource solution while highlighting remaining coverage limitations.
\end{abstract}
